### Problem 1: Fibonacci Sequence
Write a program that prints the first `n` terms of the Fibonacci sequence.

**Input:**
- An integer `n` representing the number of terms.

**Output:**
- The first `n` terms of the Fibonacci sequence.

**Example:**
```python
Input: 5
Output: 0, 1, 1, 2, 3
```

**Input:**
- An integer `n` for which you need to find the factorial.

**Output:**

Input: 5
